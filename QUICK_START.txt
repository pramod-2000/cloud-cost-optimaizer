🚀 STEP-BY-STEP STARTUP

1. Open terminal and navigate to backend folder:
   
   cd /path/to/cloud-cost-optimaizer/backend/

2. Start all services (builds images on first run):
   
   sudo docker compose up --build -d

3. Wait for services to start (watch logs):
   
   docker compose logs -f
   
   ✅ You'll see: "Up (healthy)" for all services after 15-30 seconds
   Press Ctrl+C to exit logs

4. Access the application:
   
   Frontend:          http://localhost:4173
   Backend Docs:      http://localhost:4173/docs
   Backend Direct:    http://localhost:8000/docs
   Database:          Internal only (port 5432)

🔧 COMMON COMMANDS

# View logs
docker compose logs -f                    # All services
docker compose logs frontend              # Frontend only
docker compose logs api                   # Backend only
docker compose logs db                    # Database only

# Restart services
docker compose restart                    # All services
docker compose restart api                # Backend only

# Access container shell
docker compose exec frontend sh            # Nginx shell
docker compose exec api bash               # Backend shell
docker compose exec db psql -U ai_cost_user # Database shell

# Check health
docker compose ps                         # Container status
docker compose stats                      # Resource usage

❓ TROUBLESHOOTING

Frontend not loading (http://4173):
   docker compose logs frontend
   docker compose restart frontend

Backend errors:
   docker compose logs api
   docker compose restart api

Port already in use:
   sudo lsof -ti:4173 | xargs kill -9
   OR change port in backend/.env: FRONTEND_PORT=4174

See DEPLOYMENT.md for comprehensive troubleshooting guide

🎯 WHAT'S RUNNING

✅ Frontend Container (Nginx)
   - Serves React SPA on http://4173
   - Handles SPA routing (/* → index.html)
   - Proxies API requests to backend
   - GZIP compression enabled
   - Caching for static assets (1 year)

✅ Backend Container (FastAPI)
   - Uvicorn ASGI server on port 8000
   - REST API endpoints
   - Swagger UI documentation
   - AWS SDK integrated
   - Database connectivity

✅ Database Container (PostgreSQL)
   - Port 5432 (internal only)
   - Data persists in postgres_data volume
   - Survives restarts
   - Health checks every 10s

═══════════════════════════════════════════════════════════════════════════════

🔄 SERVICE FLOW

User opens browser → http://localhost:4173
                ↓
         Nginx receives request
                ↓
    Is it a static file? (*.js, *.css, *.png)
       YES → Return from cache
       NO ↓
    Is it /api/*? 
       YES → Proxy to backend:8000
       NO ↓
    Is it /docs?
       YES → Proxy to backend:8000/docs
       NO ↓
       Return index.html (SPA routing)

Backend receives API request
                ↓
        Query database
                ↓
      Return JSON response
                ↓
      Client receives data & updates UI
